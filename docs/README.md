# Documentação — Aurora SIGER

Esta pasta concentra os **textos** do projeto: ensaios, pseudocódigo, fluxogramas e reflexões críticas que acompanham o código de cada fase. O código vive em [`aurora_siger/`](../aurora_siger/) e os notebooks demonstrativos em [`fases/`](../fases/); aqui ficam os documentos que explicam, contextualizam e problematizam o que foi construído.

A leitura não precisa ser linear — cada documento se sustenta sozinho. Se quiser começar pelo enredo, recomendo `etica.md` (Fase 1) ou `contextualizacao-historica.md` (Fase 2).
